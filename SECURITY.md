# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue público. Escribime a **contacto@corxargentina.com** con:

- una descripción del problema,
- los pasos para reproducirlo,
- el impacto que le ves.

Respondo dentro de las 72 horas y te aviso cuándo estimo tener el arreglo.
Si el reporte es válido, te acredito en las notas de la versión salvo que prefieras
mantenerte anónimo.

## Versiones con soporte

Se dan arreglos de seguridad sobre la última versión menor publicada.
