# Código de conducta

## Lo que se espera

- Tratar a los demás con respeto, incluso en desacuerdo.
- Criticar el código, no a la persona.
- Aceptar que quien mantiene el proyecto decide el alcance, y que un "no" a una
  propuesta no es un rechazo personal.

## Lo que no se tolera

Acoso, insultos, comentarios discriminatorios, publicar datos privados de terceros,
y cualquier conducta que razonablemente haga sentir a alguien no bienvenido.

## Cómo reportar

Escribí a **contacto@corxargentina.com**. Los reportes se tratan de forma confidencial
y se responden dentro de las 72 horas. Quien mantiene el proyecto puede editar, borrar
o rechazar contribuciones, y bloquear cuentas, cuando corresponda.

Adaptado del [Contributor Covenant](https://www.contributor-covenant.org), versión 2.1.
